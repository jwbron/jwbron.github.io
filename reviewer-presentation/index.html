Impact, by how strong the evidence is

Measured

  • Every PR and every push reviewed, in both monorepos
  • Noise reports held at trial levels after default-on
  • Cost per full review about 2.2 times the triage bot

Estimated

  • About a fifth of what the managed review would have cost for the same coverage

Reported by engineers

  • Less time per review
  • Cleaner PRs, fewer human rounds
  • Time to merge dropped
  • Preferred it to the managed review

One case: the blind rerun

While review was opt-in, a PR that skipped it caused a production incident. Run blind on that PR afterward, the reviewer caught the problem.

What I'd do differently

Get off gh-aw sooner.

GitHub Agentic Workflows got us running fast. Then every change needed a workaround, and the reviewer couldn't run locally.

Backup

Eval method

  • Repeated A/B runs with 95% Wilson intervals per case
  • A weekly drift run on identical arms to measure variation
  • Reports stamped with the corpus and matching rules, so a test change can't pass as a model gain
  • A judge pass over 3,204 findings in 203 runs
  • An audit separating real engineer feedback from bot-generated reactions
  • Transcripts captured per attempt, eval access limited to the staged case
