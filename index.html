Working with me

  1. I start with how your team works today. Before changing anything, I learn the existing workflow from the people in it.
  2. Then I pick one bounded problem. A review workflow, an agent setup, or a slow and expensive system. Something with a clear before and after, and a way to measure it.
  3. I build it with the team, not for them. Their feedback shapes it, and I own the rollout and the rough edges, not just the first version. Limits live in the system itself, not in instructions an agent might ignore.
  4. I leave something you can run. Reusable infrastructure and a real handoff, so it keeps working after I'm gone.

Writing

A series on intentional agentic work: how to keep agents aligned, finishing the job and trustworthy, drawn from building egg.

  • Intentional agentic work

    Unstructured agents fail in predictable ways. Each failure has a structural answer. Start here.

  • Give agents a contract, not a conversation

    When intent lives in a chat, agents drift. Write it down somewhere they can't quietly rewrite.

  • Reseed, don't compact

    Long agent work shouldn't depend on a summarizer deciding what to forget.

  • Agreement isn't verification

    When AI reviewers agree, that tells you their reasoning hangs together. It doesn't tell you the work is right.

  • Stop telling AI agents what not to do

    A prompt that says "don't" is a suggestion. Take the capability away instead.

  • An agent in a box

    How to sandbox an AI agent that works unsupervised, starting from the assumption that it will eventually do the wrong thing.
